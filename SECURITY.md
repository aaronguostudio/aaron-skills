# Security

Please [report vulnerabilities privately](https://github.com/aaronguostudio/aaron-skills/security/advisories/new)
using **Security -> Report a vulnerability** in the GitHub repository. Private
vulnerability reporting is enabled. If that route is unavailable, use the
contact options on [the author's website](https://aaronguo.com) to request a
private channel before sending details. Do not post credentials, customer screens
or exploit details in public issues.

The initial maintenance target is v0.1.x on the platforms documented in
README.md. No response-time guarantee is offered.

Adapters and skills are trusted executable code. Review their sources and
dependency changes before using customer accounts. The capture HTTP/host guard
is not a sandbox and cannot prove server-side read-only behavior. Session files
and recordings stay local; automatic screen redaction is not provided. Inspect
screens, captions and generated pages before sharing.

Ordinary verification uses public loopback fixtures and mocked voice synthesis.
Use your own provider account only when narration is requested and authorized.
