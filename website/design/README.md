# Current visual direction: Workflow Canvas

The accepted homepage now uses a white surface, near-black Inter typography,
cobalt accents and a flat workflow illustration. The three released skills form
a compact Capture / Film / Share directory. Use the current implementation in
`../src/` and the flat illustration in `../src/assets/workflow-canvas/` as the
visual reference. The bilingual GitHub READMEs use this same identity and the
approved blue/white showcase covers.

Understand, Build and Verify remain future directions. Shape remains a separate
source-checkout preview, not part of the released Demo installation.

## Historical artwork

# Original Orbital Workshop target

`source-homepage.png` is the first design shown to and selected by Aaron on
2026-10-17. It used a warm ivory surface, coral/copper accents, generous
editorial typography, floating miniature workstations, five-stage workflow,
and open three-column Demo skill showcase.

The original implementation used real HTML for page text and controls;
individual generated transparent illustrations are in `../public/art/`.

Desktop reference: 1024 × 1536 image pixels. The initial design brief requested
1440-wide desktop; the generated reference's actual raster dimensions are used
for direct QA. Responsive layouts adapt this composition without clipping text
or inventing additional released skills.
