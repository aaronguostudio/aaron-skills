# Changelog

## 0.2.0 — 2026-10-19

- Add 32 reusable presentation-cover presets with clean artwork and editable
  title, subtitle, Logo, presenter, date and palette. Export standalone PNG/WebP
  covers and reuse the same configuration for video openings.
- Let Film recommend a small visual shortlist from the content and brand; users
  choose in the conversation or browse the bilingual website gallery, customize
  a preview and copy a brief back to their agent. Runtime rendering works offline.

- Accept ordinary commit emails and GitHub merge identities without rewriting
  history; retain reachable-history privacy checks and independent secret scans.
- Verify both FFmpeg tools before CI media tests, retry incomplete Windows
  dependency installation, and refuse missing/broken ffprobe explicitly instead
  of reporting a missing sync marker. Required sync tests no longer silently skip.

- Preserve npm manager shim dispatch, add Cursor skill registration and isolated
  coexistence guidance, and distinguish an activated runtime from a failed smoke
  check with a usable retry command.
- Reveal and settle controls before recording clicks, including nested scrollers
  and sticky headers; identify failing focus matches while retaining grouped
  highlights. Keep wide wordmark logos readable within bounded presentation slots.
- Align host validation documentation, initial UI state, telemetry exceptions and
  one-time narration setup. Route legacy guided-demo documentation to the shared
  recorder helpers and improve synchronization-probe diagnostics.

- Add short website video showcases for a public blog and a fictional signed-in
  review flow, with three independent presentation/explanation recipes, generic
  English AI narration, captions, and read-only CDN delivery checks. Preserve
  frozen benchmarks and keep raw recordings, sessions and personal profiles out
  of source control.
- Present Aaron Skills as a collection of senior-engineer workflows and tools,
  with Demo as the first bundle; add an English/Chinese overview and setup.
- Add a shared platform layer, Ubuntu 24.04 and native Windows x64 installation,
  commands, private state, rendering and recovery while retaining macOS behavior.
- Use native Windows launchers, transactional managed skill copies, NTFS DACLs
  and Windows locks; no WSL, Bash or symlink privileges required by the runtime.
- Validate real Windows 11 ordinary-user and macOS workflows, Ubuntu container
  workflows, Unicode/spaced paths, revision integrity, playback, clipboard,
  synthetic sign-in/session reuse, repair and uninstall. Add three-platform CI.
- Keep runtime acceptance separate from new native LLM-host certification.

## 0.1.0 — 2026-10-17

- Demo Capture, Walkthrough Video and Paste Ready Update share a local toolkit.
- Exact business-field assertions and saved evidence geometry support checked
  highlights and offline caption/highlight revisions without replaying writes.
- Final rendering validates evidence coverage regardless of CLI option order;
  dry-run never calls narration providers or writes output files.
- macOS setup supports Codex and Claude Code registration, doctor, public smoke,
  repair and managed-link uninstall. User data and unrelated tools are preserved.
- Runtime dependencies are pinned, including Remotion 4.0.536. Explicit source
  export prepares a separate public history with privacy and secret-scan gates.
- Shared deterministic checks, TypeScript validation and CI configuration cover
  the public implementation. Further OS/harness/provider support is Phase 2.
